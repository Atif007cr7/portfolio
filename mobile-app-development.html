Pricing

Pricing approach

Every project is quoted after a short discovery call, as a fixed price for a clear scope or an hourly/monthly estimate for ongoing work. The main things that affect cost:

  • Number of screens and user roles
  • Whether a backend and admin panel are needed
  • Payments, maps, chat or other integrations
  • Offline support and real-time features
  • Design work and number of revisions

FAQ

Common questions

Do you build native or cross-platform apps?

Mostly cross-platform with Flutter, which gives near-native performance on Android and iOS from one codebase. I use native Java for Android-specific modules when a project needs it.

Will you publish the app on the Play Store and App Store?

Yes. I handle signing, release builds, store listings and review submission. You'll need your own developer accounts so the apps are published under your name.

Can you also build the backend and admin panel?

Yes, that's one of my main strengths. I build the API, database and admin panel with Laravel, FastAPI, Node.js or Serverpod, and deploy it for you.

Can you take over an existing app?

Yes. I start with a code review, fix what's urgent and then continue development.
